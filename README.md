## What it does

`main.ts` (Node 22) writes one line — the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer — to `/output/entry.txt`.

```
WARNING: The human wearing this label will read it, laugh, and do the exact thing it warns against. This label included.
```

## Run

```sh
node main.ts
cat /output/entry.txt
```
